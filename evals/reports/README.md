# Eval reports

Generated by `npm run eval` (see `../README.md`). Each run writes:

- `<date>.md` — the human-readable per tool × case score table, with a **Δ vs prev**
  column and the weakest-aspect notes.
- `<date>.scores.json` — machine-readable averages, used as the delta source for the
  next run.

**Baseline / after workflow.** Run the harness once *before* editing prompts and
commit that report (the baseline); run it again *after* and commit the delta. This
is how Phase 3's "the weak tools improve, no tool regresses" claim is measured.

These reports are **generated, never hand-authored** — fabricating scores would
corrupt the only quality instrument the project has. No baseline is committed yet
because it requires an `ANTHROPIC_API_KEY` and a paid run.
