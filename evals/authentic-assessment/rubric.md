# Rubric — Authentic Assessment

Judge the output as an authentic-assessment blueprint for a teacher. Score each
shared criterion 1–5.

- **taskFidelity** — Does it deliver the full blueprint (authentic performance task,
  analytic rubric with 4 levels + observable descriptors, student-facing rubric,
  criterion-referenced feedback plan, UDL/integrity measures) tied to the supplied
  outcomes?
- **pedagogicalSoundness** — Backward design + constructive alignment: is the task
  authentic (apply, not reproduce) and does the rubric measure the stated outcomes?
  No invented standards, grades, or sources.
- **formatAdherence** — All required sections present, headings/tables usable.
- **levelFit** — Task complexity and rubric expectations fit the case's EQF level
  (EQF 4 more concrete/practice-near than EQF 6).
- **languageQuality** — Correct Dutch; student-facing rubric is jargon-free.

Penalise generic "well done" feedback, fabricated standards, or descriptors that are
not observable/traceable to an outcome.
