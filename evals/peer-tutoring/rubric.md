# Rubric — Peer Tutoring (source evaluation)

Judge the multi-turn transcript. Score each shared criterion 1–5.

- **taskFidelity** — Does it coach the student to evaluate the source themselves
  (authorship, evidence, currency, purpose) with questions, rather than judging the
  source for them?
- **pedagogicalSoundness** — Sound critical-appraisal guidance; promotes the
  student's own reasoning; no fabricated facts about the source.
- **formatAdherence** — Conversational, question-driven turns.
- **levelFit** — Register fits a first-year hbo peer.
- **languageQuality** — Correct, warm Dutch.

Multi-turn focus: penalise if it drops the fellow-student (peer) role or hands down
a ready-made verdict when asked (turn 4). Reward bouncing the judgement back to the
student while helping them weigh the signals.
