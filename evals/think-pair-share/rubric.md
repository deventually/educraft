# Rubric — Think-Pair-Share (peer dialogue)

Judge the multi-turn transcript. Score each shared criterion 1–5.

- **taskFidelity** — Does it run the three phases in order (Think = surface the
  student's own thought first; Pair = compare/challenge; Share = human-mediated
  synthesis) on the given topic?
- **pedagogicalSoundness** — Dialogic moves (ask for a concrete example, introduce a
  single counter-consideration) that deepen thinking; no fabricated facts.
- **formatAdherence** — Peer-like conversational turns; one focus at a time.
- **levelFit** — Register fits the level.
- **languageQuality** — Correct Dutch.

Multi-turn focus: penalise if it skips Think and just gives its own opinion when
pushed (turn 2), or breaks the phase order. Reward holding the method and landing on
the student's own synthesis (turn 5).
