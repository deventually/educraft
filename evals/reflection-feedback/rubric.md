# Rubric — Feedback on a reflection or PDP (feedforward@v2)

Judge the output as feedforward that a study coach discusses with a student (brief P39, 39.3): per
criterion of the assessment model, what is already strong (with a literal quote from the student's
piece) and one concrete next step, never a grade, level or verdict. The piece is anonymised: names
are codes in square brackets. The cases are fictional and were written after the prompt; the prompt
is not tuned on them (project rule for evals: tune and measure on different cases). Score each
shared criterion 1–5.

- **taskFidelity** — Does every criterion of the model get its own heading, in the model's order,
  with strengths and next steps that are about this piece? Is something a criterion asks for but
  the piece lacks named as a next step, not filled in? Does it **handle the known error** when the
  case description names one? Missing a named known error caps this criterion at 2.
- **pedagogicalSoundness** — Are the next steps concrete actions the student can take in the next
  version (not "could be better")? Does it fit the reflection model (for ALACT: looking back,
  awareness, alternatives, trial)? About the work, not the person; deficit-free.
- **formatAdherence** — `###` per criterion, bullets with **Sterk:** / **Volgende stap:** (or
  **Strong:** / **Next step:**), no introduction, and the exact closing sentence ("Dit is
  feedforward, geen beoordeling. LimeOnIt bewaart deze feedback niet." / "This is feedforward, not
  an assessment. LimeOnIt does not keep this feedback."). Finished, not cut off.
- **levelFit** — Fits the level in the context (mbo, hbo); written to the student as "je" /
  "you" so the teacher can pass it on.
- **languageQuality** — Correct, natural target language; in Dutch no anglicisms where a Dutch
  term exists.

## Hard checks

Each check is answered from the output itself and the case inputs. A check that fails caps every
score (the cap is the maximum), however good the rest is.

- **missedKnownError** (cap 2): The case description names a known error in the input. Did the output fail to handle it as the case description says?
- **judged** (cap 2): Does the output give a grade, a mark, a level (such as onvoldoende, voldoende, goed, excellent or a letter) or say whether the student meets a criterion or passes?
- **realName** (cap 2): Does the output contain a person's name that is not a code in square brackets and not a role?
- **noTextReference** (cap 2): Does the output fail to point to the student's piece: a criterion whose strengths quote nothing from the piece although the piece has something on it, or a quote that is not literally in the piece?
- **personalAdvice** (cap 2): Does the output give advice about the student's health, home situation or money, or make a diagnosis?
