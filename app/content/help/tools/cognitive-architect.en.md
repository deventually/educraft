## When to use this tool

Cognitive Architect redesigns an existing assignment into an **AI-supported learning activity**, in four stages: an analysis of your activity against six learning principles (such as retrieval practice and elaboration), a prompt for your students, a quality check of that prompt, and a prompt that assesses your students' conversations. Use it when an assignment can now be done by AI without learning anything, and you want students to do the thinking themselves.

## How it works

This is a **multi-stage tool**. Each stage builds on the previous one: the output of stage 1 feeds stage 2, and so on. You work through the steps one at a time.

1. Complete stage 1 (the analysis) carefully — everything after builds on it.
2. Only generate the next stage once the previous one is right; you can regenerate a stage.
3. Read the final result as a whole: does the student prompt really make students recall and explain, and does the assessment prompt check that?

## Tips

- **Invest in stage 1.** A sharp analysis makes every later stage better.
- **Set a rich [context profile](/help/context-profiles)** — with multi-stage output, context counts double.
- **Unhappy with a stage?** Regenerate *that* stage before moving on.
