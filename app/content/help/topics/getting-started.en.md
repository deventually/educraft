# Getting started

LimeOnIt turns evidence-based teaching methods from *The Pedagogical Promptbook* into working tools for higher professional education. Here's the four-step flow:

1. **Pick a tool.** Every tool is on the home page. Filter by **For instructors** or **For students** to find what you need faster.
2. **Set your teaching context.** Under **Teaching context**, create a profile (programme, course, level, professional field). That profile is woven into every prompt automatically, so the result fits *your* teaching. See [Setting your teaching context](/help/context-profielen).
3. **Generate or start a conversation.** One-shot tools you fill in and generate in one pass. Chat tools hold a conversation with you: start from a suggestion or type your own message.
4. **Save and reuse.** Results appear under **Projects**, where you can re-read, copy, export, and delete them.

## Tips

- **Better profile, better result.** The more concrete your context (professional field, domain framework), the more usable the output.
- **View the original prompt.** On each tool page, *View original prompt* shows the evidence-based prompt underneath.
- **Output is a starting point.** Everything is yours to edit — review and revise before using it with students.
