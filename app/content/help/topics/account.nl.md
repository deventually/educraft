# Je account

Je account vind je via het menu rechtsboven, onder **Account**.

## E-mailadres en wachtwoord

Je kunt het e-mailadres wijzigen waarmee je inlogt, en een nieuw wachtwoord instellen (minstens 10 tekens). Beide vragen eerst je huidige wachtwoord.

Stel je een nieuw wachtwoord in, dan word je op al je andere apparaten uitgelogd. Het apparaat waarop je het wijzigt, blijft ingelogd.

## Tweestapsverificatie

Met tweestapsverificatie vraagt LimeOnIt na je wachtwoord om een code van zes cijfers uit een app op je telefoon. Wie alleen je wachtwoord kent, komt er dan niet in.

1. Kies op **Account** voor *Tweestapsverificatie instellen*.
2. Scan de QR-code met een authenticator-app, zoals Microsoft Authenticator, Google Authenticator of de app Wachtwoorden op een iPhone.
3. Typ de code die de app laat zien.
4. Bewaar de **herstelcodes** op een veilige plek. Ben je je telefoon kwijt, dan log je in met een van die codes. Elke code werkt één keer.

Raken je herstelcodes op, maak dan nieuwe. Voor beheerders is tweestapsverificatie verplicht.

## Uitloggen op al je apparaten

Na 8 uur zonder activiteit word je vanzelf uitgelogd. Ben je ergens ingelogd gebleven, bijvoorbeeld op een computer op school? Kies dan op **Account** voor **Overal uitloggen**. Je wordt dan op al je apparaten tegelijk uitgelogd, ook op het apparaat waar je nu bent.

## Taal

Bovenaan elke pagina wissel je tussen Nederlands en Engels. De tools maken hun resultaat in de taal die je bij *Taal van uitvoer* kiest.

## Welke AI-modellen je kunt gebruiken

De beheerder bepaalt welke AI-modellen voor jou beschikbaar zijn. Je kiest uit die set onder **Geavanceerd** op de toolpagina.

## Je teams

Zit je in een team, dan staat dat op **Account**. Lid zijn deelt niets van je werk. Zie [Teams en delen](/help/teams).

## Je account verwijderen

Onder **Account** kun je je account zelf verwijderen. Typ het bevestigingswoord en je account wordt direct verwijderd, samen met je opgeslagen werk, onderwijscontexten en gebruiksgegevens. Dit kan niet ongedaan worden gemaakt.
