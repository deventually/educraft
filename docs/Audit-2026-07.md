# LimeOnIt Audit — July 2026

Full-codebase audit performed 2026-07-03, judged against the bar the product is headed for: **a commercial foundation** (on-prem installs per institution, preceded by an invite-only test-drive, with a hosted multi-tenant SaaS for small institutions as a later option). Four parallel deep-dives were run — architecture, security/cost, testing/delivery, prompt quality — and all top findings were verified by hand in the code.

The remediation for everything below is specified in [`docs/implementation/`](implementation/README.md) (P-series session briefs); the roadmap and decisions are in [`Improvement-Plan.md`](Improvement-Plan.md).

## Verdict

**The architectural core is genuinely good. The operational and product-quality layers are not deployable.**

What holds up under inspection:

- **Tools-as-data is real.** `app/routes/tool.tsx` dispatches cleanly on `tool.mode`; there is no per-tool control flow anywhere. Capability grows by data addition, exactly as AGENTS.md claims.
- **Registry validation is comprehensive** (`app/lib/registry/validate.ts`): every placeholder, model id, and stage dependency is checked.
- **The provider abstraction doesn't leak.** Nothing outside `app/lib/ai/` imports provider SDKs.
- **349 tests pass in ~2s** across 50 files, with real assertions (tool tests check parity, placeholders, required fields; component tests include axe). No skipped tests.
- **Secrets, XSS, and upload claims are true**: `env.server` is server-only, no `dangerouslySetInnerHTML` anywhere, image uploads have a MIME allow-list + 5 MB cap + max 10.
- Heavy deps (`unpdf`, `mammoth`) are correctly lazy-loaded; commit hygiene is good; no TODO/FIXME litter.

## Notes on calibration

- The drizzle advisory (#10) was reported as "critical" by automated audit; hands-on review downgrades it: the app never passes user input as SQL identifiers. Patch it, but it is not an active hole.
- Component prop-drilling, module depth, and i18n structure are in good shape; this audit found no god-files and no dead code of consequence.
