- **Standaardmodel per instelling, team en docent (BESLUIT-2026-11-18-4):** tools starten niet
  meer altijd op Sonnet. Beheer kiest het standaardmodel van de instelling onder Beheer → Tools →
  Modellen; een teamleider (of beheer) kiest dat van het team op de teampagina; een docent kiest
  zijn eigen op Account, en beheer kan dat ook op de personenpagina. Iedereen kiest alleen uit de
  modellen die hij mag gebruiken; de limiet per maand blijft gelden. Ook een model dat beheer zelf
  toevoegde (zoals MiniMax via OpenRouter) kan de standaard zijn.
